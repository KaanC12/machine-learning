# Introduction

Machine learning is a way to train a computer to learn from data and ultimately make decisions without being explicitly coded to perform specific tasks, and is often used when analyzing large data sets as opposed to manually analyzing the data as this is difficult and inefficient."

Our chosen project is based upon using machine learning to analyze the given wine reviews dataset and how information pertaining to wine is used to predict.

The data set used in this project is collected from Kaggle. This data set consists of reviews of wines from various countries of the world. This data set gives insights into various characteristics of wines such as the country of origin of the wines, the prices of these wines, the types of wines being reviewed, ratings of wines by people, as well as the sommelier’s name reviewing the wines. This data set is quite large with various data set characteristics; thus, it can be used to practice various concepts of data analysis models.
